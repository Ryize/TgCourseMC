## Описание проекта

 Бот написан для управления курсами и студентами в мессенджере на Python, с использованием библиотеки PyTelegramBotAPI. Имеет клавиатуру и способен выполнять различные административные функции.

## Инструменты

Проект написан при помощи языка программирования Python, версии 3.11.
Все используемые библиотеки находят в файле requirements.txt.
Пожалуйста, учитывайте это при добавлении в свой проект.

## Использование
1. Убедитесь, что в вашей системе установлен Python.
2. Клонируйте или загрузите проект на свой локальный компьютер.
3. Откройте терминал или командную строку и перейдите в каталог проекта.
   
### Запуск программы
1. Создайте виртуальное окружение и установите зависимости из
   `requirements.txt`.
2. Скопируйте `.env.example` в `.env` и заполните значения.
3. Экспортируйте переменные и запустите `main.py`:

   ```bash
   set -a
   source .env
   set +a
   python main.py
   ```

## Проверка решений CourseMC

Для защищённой интеграции задайте:

- `COURSEMC_BOT_API_TOKEN` — общий секрет сайта и бота;
- `COURSEMC_API_BASE_URL` — по умолчанию
  `https://coursemc.ru/api/v1`;
- `COURSEMC_TEACHERS` — JSON-объект с доверенным соответствием Telegram
  user ID логину преподавателя в Django, например
  `'{"814401631":"teacher_login"}'`;
- `COURSEMC_SOLUTIONS_POLL_INTERVAL` — период проверки в секундах, по
  умолчанию 60.

Если на сервере ограничен прямой доступ к Telegram API, задайте
`TELEGRAM_PROXY_URL` (например, `socks5h://127.0.0.1:9051`). Значение
применяется ко всем запросам `pyTelegramBotAPI`.

При запуске соответствия преподавателей записываются в `users.db`. Там же
постоянно хранятся курсоры, обработанные `submission_id`, уведомления и
незавершённый ввод комментария. Логин проверяющего никогда не берётся из
текста сообщения Telegram.

Фоновая проверка запускается автоматически из `main.py`. Для отдельной
диагностики тестов без подключения к Telegram и CourseMC выполните:

```bash
BOT_DATABASE_PATH=:memory: python -m unittest discover -s tests -v
```
   
## Содержание

Проект состоит из следующих файлов:
1. admin.py: административные функции.
2. api_worker.py: работа с API.
3. billing.py: управление платежами.
4. bot.py: основной код бота.
5. config.py: конфигурация проекта.
6. keyboard_mixin.py: управление клавиатурой.
7. main.py: запуск бота.
8. models.py: модели данных.
9. requirements.txt: список зависимостей.
10. thread.py: многопоточность.
